Crie uma plataforma SaaS profissional de análise de performance esportiva para voleibol chamada "Vôlei Performance Pro".

O objetivo é construir um sistema utilizado por clubes, treinadores, analistas de desempenho e atletas para monitoramento técnico, físico e tático.

Não crie apenas um dashboard visual. Construa uma aplicação completa com arquitetura preparada para produção.

STACK:

- React + TypeScript

- Tailwind CSS

- Componentes modernos e responsivos

- Supabase como backend

- PostgreSQL para banco de dados

- Autenticação com níveis de acesso

- Storage para fotos e arquivos

- Gráficos interativos

IDENTIDADE VISUAL:

Criar uma interface premium semelhante a softwares profissionais de análise esportiva.

Características:

- Tema escuro moderno

- Design minimalista

- Cards com métricas

- Gráficos profissionais

- Navegação lateral

- Layout responsivo para desktop, tablet e mobile
